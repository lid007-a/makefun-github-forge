A standalone GitHub-compatible git forge in TypeScript, using only the Node 22 standard library: git smart HTTP (upload-pack v0/v2, receive-pack), REST API v3, GraphQL v4 and MCP, all sharing one deterministic in-memory store.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 node main.ts
```
